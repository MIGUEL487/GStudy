## Application rules

- Use TanStack file routes for home, subjects, notebooks, and settings so navigation remains shareable and supports browser history.
- Keep a per-account browser cache for offline use and synchronize it through revision-checked Supabase account documents; preserve legacy data and concurrent notebook edits, and report failed local or cloud writes instead of claiming success.
- Put study data operations in a browser-safe model and shared React provider so notebook and course creation use explicit IDs rather than mutable global selection.
- Pre-optimize interactive dependencies together and reject outdated optimizer requests so stale preview tabs cannot mix React instances after dependency discovery.
- All study AI tries native Gemini with server-only BOARD_AI_* configuration first, then native Groq with GROQ_API_KEY, then OpenRouter with OPENROUTER_API_KEY on technical failures. Old GROK_* and XAI_API_KEY settings are ignored; never route a Groq request to xAI or reinterpret a grok_ key as Groq. Do not switch merely because a Gemini generation takes 25 seconds; preserve the healthy primary request and load the Groq SDK only after a primary failure. Keep separate text/vision models and preserve structured-output validation, session accounting, safe error logs and server-only keys. Groq PDF fallback uses extracted text only and must never claim to read diagrams or scanned pages. OpenRouter must use only explicit :free models with zero-price provider routing; PDFs must explicitly select the free cloudflare-ai parser, never the paid default or paid OCR. Preserve the original PDF and explain the limits of document-to-text conversion.
- Keep Aprender activity trails separate from Rumo à prova exam plans in navigation, lists, counts and destinations. Preserve existing preparation metadata and learning progress; upgrades add a guide without replacing concurrent account edits. Exam guides use their own session completion keys. Resource links must be app-constructed searches or compatible URLs from grounding sources, never arbitrary AI-generated links. Label unverified recommendations clearly.
- Preparation videos use the official YouTube embed and API/oEmbed metadata; preserve channel attribution and controls, do not bypass embedding restrictions, and derive clip boundaries only from published chapters. Prefer Universo Narrado, Universo Narrado Militares for military exams, and Pedro Asaad where relevant. Private Drive folders are not library sources. Free PDFs require explicit work-level commercial-compatible rights and an official government/education source, not a generic site footer. Unknown or noncommercial rights permit only a verified HTML catalogue link. Paid books link to Amazon Brasil products from researched sources, or clearly labelled Amazon searches. Never rehost PDFs.

- Rumo à prova researches complete public exam/olympiad programs without requiring one subject. School exams request a subject only when content is not already identified; time/target are collected once, and the goal dial snaps to 5%. Preparation practice offers only quiz and flashcards under /preparar, shares Aprender's daily per-mode quota, preserves topic completions and uses the focused-test navigation.
- OpenStax is an additional trusted educational publisher. Its public CMS API provides book-level licence/author/PDF metadata, verified again before reading; never infer rights from a default site footer, release NC, hidden/unlisted or private sources or invent a Portuguese edition. Earlier editions may be offered only when their exact API record still declares compatible rights and their original PDF is available; mark them as earlier editions and never transfer rights through redirects to a newer NC edition. Keep direct public catalogue searches clearly labelled as searches and preserve videos during a book refresh.

- Preparation libraries recommend only Portuguese editions, including paid books. Never translate a foreign title to imply a Portuguese edition; publisher language metadata overrides AI claims. Preserve videos when refreshing old library caches for this language policy.
